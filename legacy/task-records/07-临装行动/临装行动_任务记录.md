# 临装行动_任务记录

## 任务目标

- 新增右侧临时装备栏，提供 1 个可无限拖入卡牌的格子。
- 拖入右侧临时装备栏的卡牌只在当前波次提供效果。
- 新增行动次数，默认 3 次。
- 行动次数只约束左侧装备栏的拖入、拖出和互换。

## 工作区域

- 核心文件：`outputs/游戏策划/炮台立项/炮台射击_可玩原型.html`
- 备份文件：`outputs/游戏策划/备份/任务07_临装行动_炮台射击原型.html`
- 任务记录：`outputs/游戏策划/任务记录/07-临装行动/临装行动_任务记录.md`

## 修改内容

1. 在战场右侧新增“临时心意”装备栏。
2. 右侧临时格支持反复拖入卡牌，拖入后卡牌从原位置移除，效果叠加到当前波次。
3. 下一波开始时自动清空右侧临时卡效果。
4. 左侧“魅魔装备”栏新增行动点显示，默认每波 3 次。
5. 下方卡槽与左侧装备栏之间的拖入、拖出、互换会消耗行动点。
6. 行动点为 0 时，继续操作左侧装备栏会被拦截并提示。
7. 右侧临时格从下方卡槽拖入不消耗左侧行动点；若从左侧装备栏拖出到右侧，则按左侧拖出规则消耗行动点。

## 验证结果

- 脚本语法检查通过。
- 浏览器实测通过：
  - 两张测试掉落可拾取并自动合成。
  - 卡牌拖入右侧临时格后，下方卡槽移除该卡，右侧显示投入数量与卡牌摘要。
  - 右侧临时卡效果即时计入炮台属性，且不扣下方卡槽到右侧的行动点。
  - 左侧装备拖入、拖出、再拖入后，行动点从 3/3 变为 0/3。
  - 第 4 次左侧装备拖出被拦截，提示“本波左侧装备行动次数已用完”，卡牌仍留在装备栏。
