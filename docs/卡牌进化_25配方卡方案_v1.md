## 0. 产物通用契约

### 0.1 配置字段（每张产物卡）

```ts
{
  id, recipeOnly: true,
  category, synergyTags,            // 按产物形态自定
  primaryGod: <锚点方>,             // 载体所属神，复用现有 def.god 兼容路径
  sourceGods: [可变方, 锚点方],     // 图鉴/遥测/未来神印；不建遗物匹配机制
  stars: { '6': { tier:'transform', equip:[...] } },   // 仅 6★，无 evolutionTree
  identityContract, textKey, affixPool（沿用 primaryGod 神系模板）
}
```

配方定义按 v2 §12.1 `EvolutionRecipeDef`（`recipeType` / `variableGod` / `anchorGod` / 双方 `minStar: 5` / `outputStar: 6`，无 `allowedPhase`）。配方 id 命名 `r_<可变卡>_<锚点卡>`；产物记录 `RecipeLineage`，**不继承材料分支效果**（v2 §9.1，分支回响留作后续扩展）。

### 0.2 设计红线（每张产物已自检）

1. `onKill`/`onBreach` 效果一律按**事件坐标**（V8）；2. 绑定内不重复声明取最大/覆盖类原子；3. `requiresSource` ∈ {weapon, chain, dot}；4. 依赖「每命中各触发一次」只能走贯穿/分裂；5. 产物不得作为任何配方的材料；6. 产物是**配方卡白名单**：可跨神使用身份原子（V6 豁免通道），但每个身份原子的使用必须来自对应材料神。

### 0.3 八条硬审核（v2 §8.1）＋方向性判据（§8.2）

每张产物在其条目末尾给出「八审」行：①全新核心动词 ②≥2 体验维度改变 ③因果闭环 ④删任一材料身份则概念不成立 ⑤不能用「A 效果 + B 效果」概括 ⑥改变构筑行为 ⑦Boss 兼容 ⑧立即可见。跨神配方另附「方向对照」：同一神对两方向并排读，若可互换判退回。

### 0.4 强度口径

两卡合一净释放 1 个装备槽（`equipSlots: 3`），产物原始 DPS 不必等于两材料之和；标定口径是与同成本（32 点）自升 6★ 的贡献差。

### 0.5 B0 灰盒占位规则（决议 1）

B0 批次 25 张产物统一使用结构合法的最小绑定：`interval 2.5s → burstDamage(point=最密敌群, radius 占位)` + `passive → statBuff`（每张参数微调以避免完全同构），文案标注「灰盒占位」。灰盒产物必须通过 §13.1 全部静态校验；正式版不得以不完整矩阵上线。分批：B1 同神 5 → B2 正向跨神 10 → B3 反向跨神 10（B2 全部验收后才做 B3）。

## 2. 同神升华（5 条）——该神的毕业形态

### 2.1 天罗电网 `stormLattice` ＝ 弧光裂片 + 雷霆贯枪（迅霆）

- **核心动词：织网**。主炮换形为贯穿雷矛；每次射击的飞行路径在地面留下一条短时**导电雷轨**（zone，施加感电）；雷轨交叉处形成节点，节点周期向轨上敌人起链。
- **绑定草案**：`passive→pierce 换形(全轴贯穿)`；`onFire→导电雷轨`（groundZone 载体、内嵌 `vulnerable` 而非 dot——沿用基础卡 chainLightning 5★2「导电区」先例，非火场语义）；`onHit + requiresStatus:'vulnerable' → burstDamage`（贯穿逐个兑现）；`interval 2s → chain(targets=2, spreadStatus:'vulnerable')`（节点自动链）。
- **因果闭环**：贯穿（锚点）画轨 → 雷轨铺感电（可变的面状铺设被改造成空间结构）→ 下一次贯穿沿轨逐个兑现。玩家行为从「瞄人」变成「画线织网」。
- **体验维度**：攻击载体（换形雷矛）＋战场空间结构（可见电网）＋目标拓扑（轨网连通）。
- **Boss 兼容**：Boss 体型大、常驻感电 → 贯穿兑现每发稳定触发；雷轨叠在 Boss 行进线上等于持续增伤走廊。
- **立即可见**：第一发射击即画出发光雷轨。
- **八审**：①织网✓ ②载体+空间✓ ③画轨→铺电→兑现✓ ④删贯穿则无轨、删裂片(面状铺设)则轨无感电✓ ⑤不可拆两句✓ ⑥站位与射线选择被重新考虑✓ ⑦见上✓ ⑧首发可见✓

### 2.2 冰河世纪 `glacialEpoch` ＝ 冻土 + 凛冬重锤（凛冬）

- **核心动词：平推**。以炮台为心周期向外推进**冰川锋面**（扩张环）：锋面扫过施加寒意+叠冻结层+把敌人向外推；锋面扫过冰封目标时碎冰（burstDamage）。
- **绑定草案**：`interval 4s → 扩张环 aura(slow+freeze 层+knockback)`；`onHit + requiresStatus:'frozen' → burstDamage 高倍`；`passive → taunt 冻结体`。
- **因果闭环**：冻土（可变）的领域铺设被改造成重锤（锚点）的运动学——领域不再是静态圈，而是一记从中心砸向全场的「慢锤」。
- **体验维度**：时间节奏（潮汐式推进）＋玩家站位（锋面时机决定输出窗口）＋风险兑现（推得远=安全，敌密=碎冰收益高）。
- **Boss 兼容**：Boss 击退抗性高 → 锋面对 Boss 改为不推但施加双倍冻结层（抗性替代收益）。
- **立即可见**：进化后 4s 内第一道锋面推出。
- **八审**：①平推✓ ②节奏+站位✓ ③铺寒意→冰封→锋面碎冰✓ ④删冻土无领域、删重锤无碎冰与推力✓ ⑤✓ ⑥输出窗口对齐锋面✓ ⑦✓ ⑧✓

### 2.3 常燃火山 `volcanoCore` ＝ 熔岩池 + 灼心（焚狱）

- **核心动词：喷发繁殖**。在炮台前方生成一座**常驻火山**（持久 zone）：周期向最密敌群喷发熔弹（mortar），落点留子火场；`requiresSource:'dot'` 击杀会使火山蓄能、加快下次喷发。
- **绑定草案**：`onWaveStart → 常驻火山 zone(dot)`；`interval 3.5s → mortarMorph 喷发 + 子火场 zone(dot)`；`onKill + requiresSource:'dot' → 蓄能(statBuff 喷发频率, 封顶)`；`onHit + requiresStatus:'dot' → burstDamage`（灼心的直接灼烧供给引燃）。
- **因果闭环**：灼心（锚点）铺直接灼烧维持引燃；熔岩池（可变）的火场被改造成会繁殖的活地形——火烧得越旺，火山喷得越勤。
- **体验维度**：战场空间结构（火山＋子火场群）＋资源循环（击杀回喂喷发频率）。
- **Boss 兼容**：火山持续喷 Boss 脚下，`requiresSource:'dot'` 对 Boss 击杀无效但 dot 持续伤害全程有效。
- **立即可见**：火山实体即刻出现。
- **八审**：①喷发繁殖✓ ②空间+循环✓ ③烧→杀→蓄能→更多火✓ ④删熔岩池无火山地形、删灼心无引燃供给✓ ⑤✓ ⑥落点选择变成经营✓ ⑦✓ ⑧✓

### 2.4 永固圣域 `aegisCitadel` ＝ 圣域 + 神盾（磐垒）

- **核心动词：实体化**。壁垒外化为**环形圣墙**：波开始在核心外圈召唤 N 段墙体（summon，可阻挡、可被打坏）；墙体存在时全体 `breachReduction`；墙段被摧毁时在其位置爆发新星并击退。
- **绑定草案**：`onWaveStart → summon(wall ×N)`；`passive → breachReduction`；墙段死亡 → 该段位置爆发（summon.explodeDamageMul）；`interval 9s → 补一段墙`。
- **因果闭环**：神盾（锚点）的抽象容量被圣域（可变）的空间理念改造成看得见、有位置、会塌方的城墙——「在哪里让它破」从策略隐喻变成字面操作。
- **体验维度**：战场空间结构（实体墙）＋风险兑现（引导敌人撞特定墙段）＋玩家站位。
- **Boss 兼容**：Boss 破墙即触发爆发；墙体对 Boss 是持续减速障碍。
- **立即可见**：圣墙立即立起。
- **八审**：①实体化✓ ②空间+风险✓ ③立墙→承压→塌方反击→补墙✓ ④删神盾无容量概念、删圣域无空间化✓ ⑤✓ ⑥防线布局成为新决策✓ ⑦✓ ⑧✓

### 2.5 丰饶圣林 `goldenGrove` ＝ 蔓生 + 眷恋（丰饶）

- **核心动词：结晶化**。每次拾取在**拾取坐标**种下一棵金树（summon，上限 N）：金树周期标记周围敌人赏印、周期在树下 `extraDrop`；赏印目标死于任一树冠范围内 → 该树升级（半径/产量+，封顶）。
- **绑定草案**：`onPickup → summon(goldenTree, 上限 N)`；树实体 `interval → focusPriority + extraDrop`；`onKill + requiresStatus:'brand' → 树升级(statBuff, 按死亡坐标归属最近树)`。
- **因果闭环**：眷恋（锚点）的赏印流被蔓生（可变）的领域理念改造成**经济地形**——玩家用拾取位置做园艺规划，流量型资源第一次有了空间形态。
- **体验维度**：战场空间结构（树林）＋资源循环（拾取→种树→更多掉落→更多树）＋玩家站位（去哪里拾取）。
- **Boss 兼容**：树标记 Boss（赏印集火加成全程有效）；Boss 波掉落由树持续供给。
- **立即可见**：进化后第一次拾取即种树。
- **八审**：①结晶化✓ ②空间+循环✓ ③拾→种→标记→杀→掉→拾✓ ④删蔓生无空间实体、删眷恋无赏印流✓ ⑤✓ ⑥拾取路线变成规划✓ ⑦✓ ⑧✓

## 3. 跨神进化（20 条）——按无序神对成对呈现，两方向并排审核

### 3.1 迅霆 × 凛冬

#### 霜雷云 `thunderRime` ＝ 可变·唤雷 + 锚点·霜寒（storm→winter，primaryGod: winter）

- **核心动词：天气**。霜幕被改造成**移动风暴云**：云自动跟随最密敌群，云下持续寒意；云周期降下落雷，落雷施加感电；落雷命中「寒意+感电」双持目标时倍率提升并直接叠冻结层。
- **绑定草案**：`passive → 移动 aura(slow)`；`interval 2.5s → 云内落雷 burstDamage + vulnerable`；落雷对 `requiresStatus:'controlled'` 目标附加 freeze 层；fallback：云外落雷基础伤害。
- **因果闭环**：霜寒（锚点载体）提供覆盖平台，唤雷（可变）把「天空打击」机制注入平台——云铺寒意造条件，落雷读条件兑现。
- **体验维度**：目标拓扑（云追敌群，玩家不再控制区域位置）＋时间节奏（落雷节拍）。
- **Boss 兼容**：云锁定 Boss 时落雷全额命中；Boss 冻结抗性由「倍率提升」补偿。
- **八审**：①天气✓ ②拓扑+节奏✓ ③云铺→雷读✓ ④删唤雷无落雷、删霜寒无云与寒意✓ ⑤✓ ⑥不再手动选区域✓ ⑦✓ ⑧云立即出现✓

#### 晶脉传导 `crystalRelay` ＝ 可变·冰锥 + 锚点·连锁闪电（winter→storm，primaryGod: storm）

- **核心动词：立柱中继**。雷链每跳在跳点竖起短时**冰晶柱**（summon）：晶柱是合法链节点，链可经晶柱中继延长到本不可达的距离；晶柱到期碎裂，对周围施加寒意+小额伤害。
- **绑定草案**：`onHit → chain(spreadStatus:'vulnerable') + 每跳点 summon(crystal, 短时)`；晶柱作为 chain 搜索候选（引擎侧小改：summon 可标记 `chainRelay: true`）；晶柱死亡 → 该位置 aoe slow。
- **因果闭环**：冰锥（可变）的「冰晶实体」理念改造链的拓扑——上一条链的路径决定下一条链能到哪里，链网随战斗自我生长。
- **体验维度**：目标拓扑（链路可建设）＋战场空间结构（晶柱阵）。
- **Boss 兼容**：在 Boss 周围预铺晶柱＝对 Boss 的稳定链路。
- **八审**：①立柱中继✓ ②拓扑+空间✓ ③链→柱→更长的链✓ ④删冰锥无晶柱、删雷链无中继对象✓ ⑤✓ ⑥射击顺序变成布线✓ ⑦✓ ⑧首链立柱✓
- **方向对照**：霜雷云改造「区域怎么盖」（平台自动追踪），晶脉传导改造「链怎么走」（玩家建设拓扑）。互换即失效，方向性成立 ✓

### 3.2 迅霆 × 焚狱

#### 引雷火种 `emberSpark` ＝ 可变·静电充能 + 锚点·灼心（storm→inferno，primaryGod: inferno）

- **核心动词：敌转导体**。灼烧目标成为**活电容**：每个带灼烧的敌人周期向最近敌人放出一条小雷链（施加感电）；「灼烧+感电」双持目标死亡时在死亡坐标爆燃并留小火场。
- **绑定草案**：`onHit → dot`（维持灼烧供给，V9）；`interval 2s → 以每个 dot 目标为源起链 chain(targets=1, spreadStatus:'vulnerable')`；`onKill + requiresSource:'dot' → 死亡坐标 burstDamage + 小 zone(dot)`。
- **因果闭环**：灼心（锚点）铺灼烧，静电充能（可变）把「敌群自体放电」注入——敌人越多越密，火借电势烧得越广。
- **体验维度**：目标拓扑（敌人互相感染）＋资源循环（火生电、电标记、死亡再生火）。
- **Boss 兼容**：Boss 常驻灼烧＝常驻放电源，站位在小怪群边上时收益最大。
- **八审**：①敌转导体✓ ②拓扑+循环✓ ③烧→放电→死亡→再烧✓ ④删静电无放电、删灼心无火种✓ ⑤✓ ⑥优先点燃「群中心」敌人✓ ⑦✓ ⑧首个灼烧目标即放电✓

#### 贯日 `solarPiercer` ＝ 可变·陨星 + 锚点·雷霆贯枪（inferno→storm，primaryGod: storm）

- **核心动词：轨道打击**。主炮换形**天顶轨道炮**：每次射击变为沿目标线从天而降的贯穿光柱，沿线所有敌人逐个 onHit（贯穿语义保留），光柱走廊留下短时燃烧带。
- **绑定草案**：`passive → pierce 换形(天降光柱, 全轴)`；`onFire → 沿线 zone(dot) 燃烧走廊`；`onHit + requiresStatus:'dot' → burstDamage`（走廊内目标被点燃后由下一柱兑现——注意走廊是 zone 不挂状态，兑现供给来自附带的直接 `dot` 命中效果：光柱命中目标直接施加灼烧）。
- **因果闭环**：贯穿（锚点）提供逐个命中的兑现载体，陨星（可变）把「从天而降+燃烧地形」注入弹道——打过的线变成火线，下一炮沿火线引爆。
- **体验维度**：攻击载体（弹道变天降）＋战场空间结构（火线走廊）。

### 3.9 焚狱 × 丰饶

#### 余烬收成 `emberYield` ＝ 可变·燃灰 + 锚点·眷恋（inferno→plenty，primaryGod: plenty）

- **核心动词：灰烬货币**。灼烧即标记：任何带灼烧的目标自动获得赏印；「灼烧+赏印」目标死亡时在死亡坐标掉**余烬**（特殊安全掉落）；拾取余烬短时提升灼烧 dps（可叠层封顶）——烧、杀、拾、更旺。
- **绑定草案**：`onHit → dot`；`passive → focusPriority(优先 dot 目标)`；`onKill + requiresStatus:'brand' → 死亡坐标 extraDrop(secure 余烬)`；`onPickup → statBuff(dotDamageMul, 短时叠层)`。
- **因果闭环**：燃灰（可变）的「覆盖率=收益」被眷恋（锚点）的赏印流改造成实体货币循环——火焰的产出必须弯腰去捡，拾取路线穿过火场。
- **体验维度**：资源循环（burn→drop→pickup→burn）＋玩家站位（去火场里拾取）。
- **Boss 兼容**：Boss 常驻灼烧+赏印，掉落供给稳定。
- **八审**：①灰烬货币✓ ②循环+站位✓ ③✓ ④删燃灰无灰烬、删眷恋无标记与掉落✓ ⑤✓ ⑥拾取时机/路线被重新考虑✓ ⑦✓ ⑧首杀掉余烬✓

#### 悬赏烙印 `pyreBrand` ＝ 可变·富集号令 + 锚点·灼心（plenty→inferno，primaryGod: inferno）

- **核心动词：猎杀接力**。号令改造灼烧：波开始与周期点名 N 个目标施加**烙印**＝灼烧+赏印一体（一次施加、两个系统都读）；烙印目标承伤提升；烙印目标死亡时烙印**跳转**到最近未标记敌人（接力不熄）。
- **绑定草案**：`onWaveStart + interval 4s → 对 N 目标施加 dot + focusPriority`；`onHit + requiresStatus:'dot' → burstDamage 小额附加`（烙印目标承伤提升的实现通道——不借迅霆 `vulnerable`，豁免通道只覆盖丰饶+焚狱）；`onKill + requiresStatus:'dot' → 烙印转移(对最近未标记目标施加 dot + focusPriority)`。
- **因果闭环**：号令（可变）的目标选择哲学接管灼心（锚点）的灼烧——火不再均匀铺开，而是始终烧在「此刻最该死的敌人」身上，且永不熄灭只换宿主。
- **体验维度**：目标优先级（系统点名+玩家跟随集火）＋时间节奏（接力链维持）。
- **Boss 兼容**：Boss 出场自动获烙印（最高价值目标），全程承伤提升。
- **八审**：①猎杀接力✓ ②优先级+节奏✓ ③点名→集火→死→接力✓ ④删号令无点名、删灼心无火印✓ ⑤✓ ⑥跟随烙印集火成为主操作✓ ⑦✓ ⑧开波即点名✓
- **方向对照**：余烬收成=击杀**后**的经济回路（产出侧），悬赏烙印=击杀**前**的目标选择回路（输入侧）。不可互换 ✓

### 3.10 磐垒 × 丰饶

#### 根脉织网 `rootLoom` ＝ 可变·铁蔓 + 锚点·命运织机（bulwark→plenty，primaryGod: plenty）

- **核心动词：工事生长**。每次合成（onMerge）在战场生长一段**根脉**（summon 藤墙段，永久、有上限）：根脉伤害并减速跨越者；无突破的波次结束时全部根脉强化一档。经济操作逐波建造出一座活的迷宫。
- **绑定草案**：`onMerge → mergePulse + summon(rootSegment, 上限 N)`；根脉段自带 `aura(持续伤害 + 轻微 knockback)`（不用 `slow`——豁免通道仅覆盖两个材料神的身份原子，凛冬不在其中）；`onWaveStart → 上一波无突破则全部根脉 statBuff`。
- **因果闭环**：铁蔓（可变）的守成哲学接管织机（锚点）的合成事件——合成不再只是即时脉冲，而是永久基建；守住防线，基建就复利。
- **体验维度**：战场空间结构（永久迷宫逐波生长）＋资源循环（合成→建造→守成→强化）。
- **Boss 兼容**：根脉持续伤害并迟滞 Boss 推进路线。
- **八审**：①工事生长✓ ②空间+循环✓ ③合成→建→守→强✓ ④删铁蔓无守成强化、删织机无合成触发✓ ⑤✓ ⑥合成位置/时机=施工决策✓ ⑦✓ ⑧首次合成即生长✓

#### 福祸相生 `fortuneThorns` ＝ 可变·吉星 + 锚点·荆棘（plenty→bulwark，primaryGod: bulwark）

- **核心动词：以伤生财**。荆棘反伤累积**福缘**计量条：每积满一档，在核心旁掉落一次奖励（extraDrop）并获得短时 `breachReduction`；发生突破时立即在突破坐标结算一次大额掉落——挨打是投资，突破是分红。
- **绑定草案**：`passive → thorns`；反伤累计 → 满档 `extraDrop + breachReduction(短时)`；`onBreach(按 point) → 突破坐标 extraDrop 大额 + burstDamage 小额`。
- **因果闭环**：吉星（可变）的运气经济接管荆棘（锚点）的反伤事件——防御数值第一次直接铸造成经济产出，「被打多少」变成一条收入曲线。
- **体验维度**：风险兑现（主动承压=赚钱）＋资源循环（反伤→掉落→合成→更硬）。
- **Boss 兼容**：Boss 高频攻击=福缘快速累积；Boss 突破分红全额。
- **八审**：①以伤生财✓ ②风险+循环✓ ③承→积→掉→强✓ ④删吉星无奖励掷点、删荆棘无反伤计量✓ ⑤✓ ⑥卖血流成立✓ ⑦✓ ⑧福缘条即刻可见✓
- **方向对照**：根脉织网=主动操作（合成）建造空间，福祸相生=被动承受转化收益。不可互换 ✓
