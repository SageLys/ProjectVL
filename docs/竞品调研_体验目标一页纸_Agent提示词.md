# AI Agent 提示词：竞品调研 → 体验目标一页纸（含可检验 KPI）

> 使用方法：将下方全文复制给具备联网搜索能力的 AI Agent。

---

## 角色与背景

你是一名手游产品分析师 + 资深游戏策划。我正在开发一款**合成塔防原型**（代号 ProjectVL），核心设定：

- 炮台全自动攻击，玩家唯一操作对象是**卡牌**：拖到主画面 = 一次性消耗释放（释放点=落点）；放入装备区 = 持续规则改变（一卡两用）
- 单局结构 = **固定波次 + Boss**（无尽模式仅作数值验证，不面向玩家）
- 技能全部为功能型（无纯数值加成卡），星级带来质变（1★机制 / 2★+修饰 / 3★形态变换）
- 玩家的核心决策：合成哪些卡、装备哪些卡、何时消耗释放、升级三选一 perk

我需要你**联网调研当期（2025–2026）市场数据**，最终产出一份可指导数值调优的「体验目标一页纸」。

## 任务一：竞品调研（三个池子）

对以下三个池子各选 3–5 款代表作调研。给出的名单是起点，你应补充当前市场上更活跃的同类新品：

1. **合成塔防**：Random Dice（含 GO/Defense 系列现状）、Grow Castle、Rush Royale、Wild Castle 等
2. **幸存者like**：Vampire Survivors、Survivor.io（弹壳特攻队）、20 Minutes Till Dawn、Brotato、Magic Survival 等
3. **合成消除/三消合成**：抓大鹅、羊了个羊系、Triple Match 3D、Zen Match、Gossip Harbor / Travel Town（merge 经营）等

每款游戏收集：

- **市场数据**：近 12 个月下载量/收入/DAU 量级（Sensor Tower、AppMagic、data.ai、点点数据、七麦等公开口径），当前是上升/平稳/衰退期
- **单局节奏**：典型单局时长；波次/关卡结构；张力峰值放在哪里（波末？Boss 前？限时？）；呼吸口如何设计
- **注意力预算**：玩家每分钟大约做几次有意义决策？决策类型（放置/合成/走位/选卡）；挂机与主动操作的比例
- **难度与留存锚点**：首局/首关通过率的公开数据或社区共识；新手期卡点设计；难度曲线形状（线性/台阶/波动）
- **合成相关**（池1、池3）：每波/每局合成次数量级；合成深度（几级）；掉落物过期/溢出的处理方式

## 任务二：产出「体验目标一页纸」

基于调研，输出一页纸（≤800字正文 + 图表），包含四部分：

1. **目标受众画像**：从三个池子的用户重叠区推导——年龄段、游玩场景（通勤/睡前/碎片）、单次可用时长、对操作复杂度的容忍度、付费习惯。说明本作应主打哪个交集人群及理由。
2. **单局时长**：以 8–12 分钟为初始假设，用竞品数据验证或修正，给出结论值和波次数建议。
3. **难度曲线意图图**：画出单局内张力曲线（文本图或 mermaid 均可）。约束：张力峰值在**每波末与 Boss 前**，波间为呼吸口（合成/装备整理时间）。标注每个峰值/谷值对应的玩家心理状态与预期操作。
4. **注意力预算说明**：每分钟决策次数目标值（分波内/波间两档），并对照竞品说明为何取该值。

## 任务三：可检验 KPI 表（关键产出）

给出一张 KPI 表，每行必须包含：**指标定义（含测量口径）｜竞品基准（注明来源与数据日期）｜本作目标值｜检验方法（在原型中如何埋点/统计）**。

必须覆盖并校准以下初始假设，可增补但不可遗漏：

| 指标 | 初始假设 |
|---|---|
| 首局通关率 | ~30–40% |
| 平均每波合成次数 | ≥2 |
| 掉落过期率 | ≤20% |

建议增补方向：波间呼吸口时长占比、Boss 战时长占比、首局内三选一 perk 决策耗时、卡牌消耗释放频率等。

## 调研规范

- 优先 2025–2026 年数据；每个关键数字注明来源和日期
- 区分**实测数据 / 第三方估算 / 社区共识 / 你的推断**四种置信级别
- 关键数字至少两个来源交叉验证；找不到数据的项明确标注"无公开数据"并给出替代推断依据，不许编造
- 单局时长、决策频率类数据若无公开报道，可依据实录视频（YouTube/B站攻略）估算并注明

## 输出格式

1. 体验目标一页纸（正文）
2. KPI 表
3. 附录：分池竞品调研笔记（每款一小节，含来源链接）
