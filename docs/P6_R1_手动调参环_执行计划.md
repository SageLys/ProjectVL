### 类 H：派生只读指标（面板联动显示，不可直接调）

动任何 A/B/C 类参数时实时重算并显示，帮助人理解因果：

1. **TTK(type, wave)** = `hp(type,wave) / (damage × fireRate × hitRate)`，hitRate 按 spread 与目标半径估算；波 1–3 × 4 类型矩阵展示。
2. **入场走行时间** = (spawn 点到射程圈距离) / speed；**圈内存活走行** = min(TTK, 射程圈到突破线时间)。
3. **理论击杀深度** = 射程 − speed×TTK（击杀点距炮台距离的期望），直接预测 E5。
4. **理论稳态同屏数** ≈ (入场走行 + TTK) / 出怪间隔（interval 模式）或 targetOnScreen（budget 模式），预测 E1。
5. **每波理论时长** 与 **全局理论时长**（对照宏观约束 10–14 分钟）。
6. **每分钟掉落期望** = 击杀速率 × dropChance，预测 E3/E6。

## 5. R1-B 人工调参流程（人）

### 5.1 准备

AI 交付 A1–A3 后，人在 `npm run dev` 打开游戏，确认面板/HUD/导出可用（10 分钟冒烟）。任何工具问题退回 AI 修复，不带病调参。

### 5.2 调参回合制（每回合 ≈5 分钟）

每回合：选 seed → 玩波 1–3（约 90–180s，可用 timeScale 加速重复段）→ 按 30 秒检查单打分 → 只动 1–2 个参数（看联动指标预判）→ 存 preset（命名格式 `v0.N_一句话`，如 `v0.4_密度够_威胁弱`）→ 下一回合。

30 秒检查单（每波各打 1–5 分）：**有事做吗**（手闲不闲）；**有东西看吗**（屏幕空不空）；**有紧张感吗**（敌人逼近可见吗）；外加整体分 1–5。

建议调参顺序（可打破，仅供起点）：

1. **密度骨架**：先切 `budget` 模式试 `targetOnScreen`（P6 预判起点：波1 敌数 8→20+、同屏 4–10），或 interval 模式压 `spawnInterval.base`。只看"有东西看"。
2. **威胁与 TTK**：调 range（预判方向：430 大幅下调）/ 敌 HP / damage，把 TTK 与击杀深度调到"逼近可见"。只看"有紧张感"。
3. **操作节奏**：调 dropChance / dropLifetime / xpNeedBase，把"有事做"调到手上不闲不忙。
4. **波尾与呼吸**：调 waveEndSprint 与 betweenWaves，找波形冲刺感与喘息比例。
5. **跨波曲线**：确认波 1→3 递进感（perWave 类参数）。

## 6. R1-C：AI 如何从三件套确定所有指标（回填算法）

输入：§5.3 三件套。逐步执行：

1. **会话筛选**：仅纳入 `overall ≥4 且各检查项 ≥3` 的会话（≥3 个）；反例会话单独留作"无聊侧"对照。
2. **逐会话计算**：按 §3.1 定义对每个纳入会话算出波 1/2/3 各自的 E1–E7 + 前 90s 切片。
3. **跨会话聚合**：每指标每波取中位数，得"手感观测值"。
4. **容差定门槛**：地板类（E1、E3、E4、E6、E7）门槛 = 观测中位 × 0.8 向下取整；上限类（E2）= 观测最大 × 1.25 向上取整到 0.5s；区间类（E5）= 观测 P50 ± 观测 IQR。容差系数写入文档，允许用户改。
5. **无聊侧校验**：用反例会话检查每个门槛——若某门槛连"无聊配置"也能通过，标红并收紧（该指标失去判别力）。
6. **冲突检查**：用手感基线 config 推演整局理论时长/难度，与 §3.2 宏观约束对照；冲突项**只列清单不擅自改**，作为 R4 议题。
7. **产出**：`docs/P6_新KPI体系_v2_定版.md`（每指标：定义、门槛、来源会话数、无聊侧判别力结论）；`scripts/checkExperienceKpi.*` 校验脚本（吃 telemetry JSON，输出逐指标 PASS/FAIL，供 R3 仿真器直接复用）；注意力预算两层数值（回填 §3.3 空格）。

**验收标准**：(1) 定版表无留空格；(2) 校验脚本对 3 个满意会话全 PASS、对反例会话至少 3 项 FAIL（判别力证明）；(3) 冲突清单明确（可为空）；(4) 全流程可从三件套一键重跑（幂等）。

R0 随后修订（见 Prompt 5），R2/R3/R4 按 P6 主文档执行，其中 R3 的 bot 校准数据源改为本轮 telemetry 会话文件（原文 `getAttentionTelemetry()` 尚不存在，由 A2 遥测层替代）。
