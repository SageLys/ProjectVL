## 3. 解释器缺口修复的独立验证（`tests/effectInterpreter.test.ts` 新增 describe 块）

| 机制 | 验证点 |
|---|---|
| `triggerParams.requiresSource` | 无 source 的击杀不触发绑定；`source='chain'` 的击杀触发绑定（通用过滤，非连锁闪电专属） |
| `triggerParams.requiresStatus` | 未冻结的击杀不触发；冻结中的击杀触发（通用过滤，非冰霜专属） |
| `expiryConvert` 落地 | 装备 `expiryConvert` 后过期掉落按 ratio 折算经验；未装备时纯计入 `expired`，经验不变 |
| 召唤物 `respawnOnce` | 首次摧毁在新位置重生（`respawned=true`）；二次摧毁正常移除 |

## 4. Bounty 精英机制

代码路径：`waveSystem.startNextWave`（掷骰 `bountyPending`）→ `enemySystem.spawnEnemy`（打精英标记）→ `enemySystem.tickBounty`（倒计时/超窗清空）→ `game.ts onBountyTap` → `enemySystem.acceptBountyTap`（接单+狂暴）→ `combatSystem.findTarget`（接单精英优先索敌）→ `damageSystem.killEnemy`/`dropSystem.rollBountyDrops`（肥而急奖励）→ `drawEnemies.ts`（金色倒计时环/接单描边）。

未在批次1新增独立单测文件；行为在人工实玩（本文档 §5）中核对。后续如需回归保护，可在 `tests/enemySystem.test.ts`（若无则新建）补充：spawn 打标 / 倒计时清空 / 接单狂暴数值 / findTarget 优先级 / 击杀掉落星级封顶 四条。
