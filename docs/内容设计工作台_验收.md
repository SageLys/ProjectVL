# 内容设计工作台 · 分阶段验收

入口：启动 `npm run dev` 后打开 `http://localhost:5173/design.html`。该入口只在 Vite dev server 下使用；生产 `npm run build` 不会把它放进 `dist/`。

## 阶段一 · 只读工作台

1. 打开 `design.html`，确认页头显示“配置管线已连接”，左栏按五神、融合卡、通用遗物组织，而不是按 JSON 域组织。
2. 依次展开迅霆、凛冬、焚狱、磐垒、丰饶，每神抽查 7 张名册卡。重点对照历史快照 `docs/ProjectVL_内容设计审阅手册_2026-07-28.pdf`：
   - `chainLightning`：3★/5★各三分支、4★静默强化、6★公共终态、三档消耗态与词条池；
   - `magmaPool`：领域里的 `params.effects` 应递归显示嵌套持续伤害，不得出现对象字面量；
   - `frozenThunder`：只显示固定 6★，且顶部显示两张材料卡与波间配方来源。
3. 依次打开五个横切视图：
   - 分支同质化：列表必须非空；抽查 `chainLightning` 的同文案分支，人工确认确属占位或待细化内容；
   - 文案完整性：矩阵应有 41 张卡，红色为缺失、黄色为占位、绿色为完成；
   - 星级功率：切换五神，检查每神 7 张卡的 3★/5★/6★原子与关键值；
   - 原子使用：应有 34 行，零使用原子高亮，展开位置可回到卡牌；
   - 词条覆盖：应有 17 行，`AFFIX_SINKS` 标为 `unsupported` 的装备轴显示警示。
4. 在打印范围中分别选择“当前实体”“当前神整章”“全部内容”，各执行一次 Ctrl+P；再选任一横切视图和“当前横切视图”执行一次。确认：
   - A4 预览无标题独占一页产生的空白页；
   - 三分支在打印时为单列；
   - 表格行、卡片块不被拦腰截断，CJK 长串可正常换行。
5. 运行 `npm run test`、`npm run build`、`npm run validate`；确认全绿，并确认 `dist/` 中没有 `design.html` 或 design 资源。

## 阶段二 · 文案就地编辑

1. 打开一张卡，只切换一个文案块到编辑态；确认机制区和其他文案块仍保持阅读态。
2. 修改一条 `evolution.<cardId>.<optionId>.summary`。右栏应立即显示 texts 候选的配置管线报告；error 禁用保存，warning 不阻止保存。
3. 保存后运行 `git diff -- src/data/texts.json`，确认 diff 只含该值；运行 `npm run validate`，确认 0 error。
4. 制造一条会被端点以 422 拒绝的文案候选；确认文件未落地、未保存输入仍保留、右栏展开端点返回的 issues。
5. 在“文案完整性”看板点击一个缺失或占位单元格；应回到对应卡牌，并直接打开目标字段的编辑态。

## 阶段三 · 机制编辑

1. 在 `chainLightning` 的 3★分支中修改 `chain.params.bounces`，保存后运行 `git diff -- src/config/base/skills.json`，确认只含该数值。
2. 抽查四类绑定入口均可原位编辑：`stars` 当前值、3★/5★分支、4★/6★公共节点、消耗态 anchors；嵌套效果继续由通用效果编辑器递归编辑。
3. 抽查卡牌词条池、amplifyAxis、设计备注、标签/类别/教学；遗物效果与池影响；融合配方材料/产出/星级/阶段。引用字段必须为下拉，不得输入自由文本。
4. 令某配方材料或名册引用指向不存在的卡（可在 `editor.html` 制造后回到本页观察，或用测试候选）；保存必须被 422 拦下，文件不落地，右栏可定位到端点 issue 路径。
5. 同批改动涉及实体域与 texts 时，确认一次保存要么全部成功，要么失败后回滚，不出现单域落地。
6. 运行 `npm run test`、`npm run build`、`npm run validate`，确认全绿。

## 数据安全复核

- 所有读取都从 `/__config/domains` 返回路径再 fetch；校验只认 `/__config/validate`；写回只走 `/__config/write`。
- 卡、神、遗物与 texts 同批保存只走 `ConfigSaveFlow.saveEntityWithTexts`；其他多域保存走 `ConfigSaveFlow.save`。
- 保存成功后刷新页面，游戏运行时才会在下一次装配时读到新配置；本工作台不提供运行时热更。
