## 1. “100%”的定义

“迁移完成”不是只看脚本数量，而是同时满足以下五个门：

1. **内容门**：当前网页版本的卡牌、词条、遗物、神池、配方、经济、敌人、Boss、波次、难度、奖励和结算均可在团结版本完整游玩。
2. **规则门**：核心规则具有团结单元测试，关键固定种子场景与网页版本的统计结果一致。
3. **表现门**：正式美术、动画、音频可以通过资源目录或可视化目录接入；素材缺失时仍有完整后备表现，不影响游玩。
4. **平台门**：竖屏触控、鼠标键盘、暂停/切后台、存档恢复和发布构建均可用。
5. **工程门**：开发调参、遥测、构建、测试、错误日志和 PR 验收形成闭环，没有未登记的占位实现。

所有条目完成后，才将 PR 从 Draft 转为 Ready。
