## 二、「装备短句被写坏了」——根因与根治办法

这一节是 v3 的核心补充。A 和 B 都要按它执行。

### 2.1 坏在哪

现状 105 条 `equip.shortByTier` 长这样：

```
chainLightning.3  已选分支强化：链弧 / 电轨 / 雷暴
chainLightning.5  叠加接口分支：引爆 / 传导 / 蓄流
chainLightning.6  终极形态：周期双链加强化
pierce.3          已选分支：穿刺 / 裂空 / 蓄力雷击
```

它罗列的是**这一档有哪几个分支可选**，不是**这张卡装上以后在干什么**。玩家从中得不到任何效果信息，等于把设计文档的目录贴到了玩家界面上。

### 2.2 为什么会写成这样（根因，不修根因换个模型还会再犯）

**根因一：这个字段本身存在真实的歧义。** `equip.shortByTier` 每档只有**一个**字符串，但 3★ 和 5★ 是**分支节点**——玩家选 A 还是选 B，装备后的实际效果完全不同。"装上后一直在干嘛"在这一档没有唯一答案。上一个执行者撞上这个歧义，选了个看似"覆盖全部可能"的退化解：把三个分支名都列出来。这是对真问题的错误回答，不是单纯的偷懒。

对照来看，`hand.shortByTier` 写得还行，正是因为消耗态锚点（`consumable.anchors` 的 1/3/6 档）与分支选择无关，是确定的，没有歧义。

**根因二：旧占位值就长这样，执行者在原地"改良"而不是重写。** 改造前该字段是 `选择 链弧/电轨/雷暴`（v4 设计表 §0.5 定的机械生成模板）。执行者把它润色成"已选分支强化：链弧 / 电轨 / 雷暴"就交差了，锚定在旧值上，从没回到"这句话该回答什么问题"。

### 2.3 根治办法

**给每一档一个唯一确定的写作对象，把歧义消灭在规则层。**

| 档位 | 节点类型 | 写什么 | 依据 |
|---|---|---|---|
| `equip.shortByTier.3` | 分支节点（三选一） | **身份契约的口语版**——不管玩家选哪条分支都成立的那件事 | 工单每张卡的「身份契约」行 |
| `equip.shortByTier.5` | 分支节点（三选一） | 同一件事 + 「开始把铺好的东西变现」这一层，用**不点名任何分支**的说法 | 身份契约 + 5★ 三接口的共性（兑现／传播／转化都是"把资源换成收益"） |
| `equip.shortByTier.6` | 公共终态（确定） | **可以且应该写具体效果**——6★ 是共享节点，所有人拿到的一样 | 工单「6★ 公共节点」的精确效果句 |

举例（`chainLightning`，身份契约是"雷链在追求者之间跳跃，并沿途施加感电"）：

```
3★  每次命中都顺着人群一路电过去，被电到的都更容易受伤
5★  电得更远，而且开始把这份"更容易受伤"换成实打实的伤害
6★  不用你动手，每 1.2 秒自动朝最近三个追求者放一轮电
```

三句都在讲效果，都不点名分支，6★ 具体到了机制。

**配套硬规则（A 遵守、B 机械校验）：**

1. `equip.shortByTier` **禁止出现该卡任何一条分支的 `name`**（工单里每条分支都列了当前名与新名）
2. **禁止出现结构词**：`已选分支`、`叠加接口`、`公共终态`、`终极形态：`、`选择 `、`分支`、`接口`
3. **禁止出现 `/` 或 `、` 连接的三项并列**（三项并列几乎必然是在罗列分支）
4. 每句必须含至少一个**机制动词或机制关键词**（电／冻／烧／推开／挡下／反弹／掉落／穿透／连锁／减速／易伤／护盾…）
5. 同一张卡的 3/5/6 三句**必须互不相同**，且**不得与 `hand.shortByTier` 任何一句相同**

`hand.shortByTier` 同样适用规则 4、5；它没有歧义问题，照消耗态精确效果写即可。

## 二、世界观与语气（最重要，前两版都是栽在这里）

**世界观**：玩家扮演一只魅魔，守着自己的地盘，击退一波波狂热扑上来的追求者。所有技能都要包装成她"拒绝 / 整治 / 反撩"追求者的桥段——电他、冻他、烧他、推开他、设陷阱勾他、反击他、顺手收走他送的东西。敌人**统一叫「追求者」**；玩家血量叫「心防」；掉落物是追求者送的「心意」。

**语气铁律**：

1. **说人话，不要文绉绉。** 禁止堆砌四字成语、书面语、刻意工整的对仗。要像现代人吐槽/发消息时会说的话。
2. **技能名不限字数、不限句式。** 可以两个字，也可以一整句带标点的话。`我不喜欢你！` 这种第一人称吐槽句是**正确方向**。
3. **反例甲（生造成语）**：`以牙还烫`、`本命桃花`、`越界天谴`、`霜打分成`、`头号通缉`、`雷罚印记`。每个字都对得上机制，但读起来像生造的成语。
4. **反例乙（机制直译）**：`连锁闪电`、`雷霆贯枪`、`霜寒`、`神盾`、`冰棺`、`熔岩池`——这是项目现在的卡名，纯功能占位、零题材，是本次要全部替换的对象。
5. **正面参照**：项目早期上线过一批名字——`直球拒绝`、`保持距离`、`冷淡处理`、`热情退烧`、`暧昧诱饵`、`带刺玫瑰`、`私人领域`、`禁入红线`。它们成立的原因是**都是约会语境里真实会说的短语**。这次可以更进一步直接用口语句子（击退卡叫「离我远点」、电系卡叫「别碰我，会电」、放狠话的卡叫「我说了不约」）。只用来体会语感，**不要照抄**。
6. **量化要求**：60 张卡名里**至少 15 个**是带标点或语气词的口语句式；四字词占比**不得超过三分之一**。上一版 61 个卡名 0 个含标点、35 个四字词，不合格。
7. **擦边尺度**：暧昧、调侃、有点占便宜的小机灵（参照上述旧名的程度），不涉及具体性内容，不低俗。
