## 1. 设计原则

1. **位置→注意力映射**：幸存者like 用走位消费风险，本作玩家不移动，风险资源改为**屏幕位置上的注意力分配**——掉落在哪、精英在哪、消耗卡落点选哪，都是空间决策。
2. **点击动词多功能化**：点击是唯一动词，承担多种功能且互相争夺（见 §7 冲突表）。每次点击都有机会成本，这是"手上轻、脑子重"的落地方式。
3. **时刻型窗口**：所有压力来自"窗口会关"（掉落过期、bounty 倒计时、解围时机），不来自 APM。
4. **复杂度预算**：设计面放宽（12 张，全类别有代表），实装面收紧（首批 7 张，42 个设计态）。设计便宜、实装贵，先把设计空间画完，实装按批次走。星级 6 档但设计态不随档数线性膨胀：只在质变锚点设计，其余星级由内插规则生成（见 §4）。
5. **题材解耦（P0-5）**：下文卡名均为机制工作名，皮肤文案经 `texts.json` 的 `textKey` 索引。

## 2. 效果原子库

原子只描述"做什么"，由上下文决定"何时何地"：装备态 = 绑定到触发器；消耗态 = 落点即时释放。**同一原子服务两种用法，是一卡两用不膨胀的关键。**

| 类别 | 原子 | 说明 | 关键参数 |
|---|---|---|---|
| 弹道 projectile | pierce | 子弹穿透 | count, damageRetention, rampPerPierce |
| | chain | 命中后向附近敌人弹跳 | bounces, damageRetention, searchRange |
| | split | 命中后分裂子弹片 | count, damageRatio |
| | ricochet | 撞场边反弹（首批未用，原子保留） | bounces |
| | aoeOnHit | 命中点小爆炸 | radius, damageRatio, falloff |
| | beamMorph / mortarMorph | 3★ 换形：光束炮 / 榴弹炮 | interval/width、radius/falloff |
| 控制 control | slow | 减速 | ratio, duration |
| | freeze | 冻结 | duration, stacksToTrigger |
| | stun | 眩晕 | duration, chance |
| | knockback | 击退 | distance, collisionDamage |
| | taunt | 嘲讽（改索敌目标） | radius, priorityWeight |
| | vulnerable | 易伤 | ratio, duration |
| 领域 domain | aura | 炮台中心持续光环（内嵌其他原子） | radiusRatioOfRange, effects[], tickInterval |
| | groundZone | 地面区域（点/环带，内嵌 dot/slow 等） | radius, duration, tickInterval, effects[], shape |
| | dot | 持续伤害 | damagePerTick, tickInterval, duration |
| | summon | 召唤物：诱饵图腾/镜像炮台/环绕球 | kind, count, hp, duration, behaviors[] |
| 经济 economy | dropRateMul / dropLifetimeMul / xpMul | 掉率/掉落时限/经验乘数 | mul |
| | extraDrop | 直接产生掉落 | count, starWeights, at |
| | expiryConvert | 过期掉落转化（破"过期即损失"） | ratio, convertTo |
| | mergeRule | 改合成规则本身（万能卡/返还） | rule, value |
| | mergePulse | 合成动作产生战斗效果 | damagePerMergeCount, radius |
| 防御 defense | shield | 炮台护盾（按可吸收突破次数计） | absorbHits, regenSeconds |
| | thorns | 反伤 | ratio |
| | breachReduction | 突破惩罚减免 | ratio |
| | novaOnBreak | 破盾新星 | damage, knockbackDistance |
| | execute | 低血线处决 | hpThresholdRatio |
| 共用 shared | burstDamage | 即时范围伤害（消耗态常用） | damageMul, radius |
| | focusPriority | 改炮台索敌优先级（bounty/烙印联动） | priorityWeight |

**正交性约束**：新增效果先问"能否由现有原子+参数组合表达"，不能才加原子。原子之间不允许隐式互相引用（组合语义由解释器叠加，如"冻结中的敌人受击退无效"这类交互规则集中写在解释器的冲突表里，P3 交付）。

## 4. 星级质变模板（硬规则 R5，v2.0 按 6★ 上限/3★ 入装/双质变节点重构）

6 档星级，**双质变节点**：3★（机制成形，入装门槛）与 6★（形态变换）之间加入 5★（第二机制）。设计预算只花在锚点档；2★/4★ 为内插档，不做机制设计。

| 星级 | 模板 | 定义 | 判据 |
|---|---|---|---|
| 1★ | material 素材/即时 | **不可装备**。两个出路：合成素材（2 张同型 → 2★）或即时消耗（该幻想的最小剂量） | 拾取时的取舍（合还是扔）3 秒内可判断 |
| 2★ | material+ 进阶素材 | **仍不可装备**。消耗态数值增强（内插），合成价值上升——2★ 是"半件装备"，消耗它开始有痛感 | 无新机制，无需学习 |
| 3★ | core 机制成形 | **首次装备体验**（入装门槛）：基础机制 + 1 个修饰符。玩家的第一件"部件" | 一句话能说清机制，修饰是"啊还会这样"的小惊喜 |
| 4★ | amplify 数值放大 | 装备态同构，沿该卡标注的**放大轴**增强（穿透+1/链+1跳/半径+~25% 等），无新机制 | 强度可感，零新学习成本 |
| 5★ | dual 第二机制 | 在 core 之上**叠加一条正交的第二机制**（多为条件触发：击杀连锁/突破反制/转化），构筑身份开始分化 | 第二机制与第一机制产生组合语义 |
| 6★ | transform 形态变换 | 可整体替换触发绑定：换形/领域化/召唤物化。构筑的"身份宣言"——玩家报 build 时说的是 6★ 形态名 | 视觉形态肉眼可辨，构筑身份改变 |

质变节奏：1★→3★ = **获得装备身份**（从弹药变成部件），3★→5★ = **机制复合**，5★→6★ = **形态变换**。合成成本（二合占位）：2★=2、**3★=4（入装）**、4★=8、5★=16、6★=32 张同型 1★ 等价。

> **⚠ 数值重标定必查项（P2 只立靶不定数）**：旧拾取预算假设（38–45 次/局）下，32 张同型 1★ 在单局**不可达**（12 卡目录、活跃池假设下同型期望仅 ~6–8 张）。6★ 的单局可达性目标必须人工拍板后反推掉落量级/活跃池大小/定向保底强度——或明确接受"6★=极限长线目标，常规局止步 4–5★"。此为数值阶段第一优先级问题。

装备骨架（人工定案 + 占位假设）：**手牌 ~7 格 + 独立装备 3 格**（方案A，局内不扩容，格数占位待标定）；装备同类型唯一（占位）；**装备可撤销/可消耗**（选项B，2026-07-14）：装备着的卡可随时拖入战场消耗释放（触发其消耗态即时效果并腾出装备位），`unequipPolicy=consume`，不设无效果的纯销毁入口；支持**喂养合成**（手牌卡与已装备同型同星直接合成升星——这是升级已装备卡的**唯一**途径，占位）。

**可消耗装备的设计意涵（选项B）**：装备态 = 持续规则改变；想反悔/救场时，把装备**消耗释放**兑现为一次即时爆发并腾出格位——这就是"一卡两用"的完整闭环：装备(持续) ⇄ 消耗(即时)，且装备着也能随时转消耗。机会成本仍在且不轻：消耗掉一件高星装备 = 失去其全程持续效果、并要重新构筑该格，故"脑子重"依然成立——压力从旧案的"永久沉没成本"变成**"何时把持续效果兑现为即时救场"的时机决策**，与"时刻型反应/救场窗口"更契合。装备时机仍是决策：早装 3★ 吃满全程收益 vs 憋到 5★/6★ 一步到位但中期裸奔。

## 5. 一卡两用硬规则（R1–R11）

| # | 规则 |
|---|---|
| R1 | 每张卡**必须**定义：装备态锚点 **3★/5★/6★**（4★ 由放大轴规则生成，不单独设计）+ 消耗态锚点 **1★/3★/6★**（2★/4★/5★ 数值内插）。消耗态 = 同一幻想的压缩即时版，只能复用该卡装备态的原子家族（不得为消耗态发明新机制） |
| R2 | 消耗释放 placement 恒为 point：**释放点 = 落点**。落点是效果的空间锚点——中心（AoE/冻结/燃海）或方向轴（贯穿），由原子语义决定 |
| R3 | 消耗即失去该卡（从卡槽移除，不返还） |
| R4 | 消耗态即时生效或持续 **≤5s**，禁止任何永久效果；强度/半径随星级按锚点+内插增长 |
| R5 | 星级质变模板见 §4：1–2★ 素材/即时（不可装备）→ 3★ 机制成形 → 4★ 数值放大 → 5★ 第二机制 → 6★ 形态变换；禁止"同构数值×1.5"冒充质变锚点（4★ 除外，它就是数值档且明示） |
| R6 | 题材解耦：名称/描述一律走 textKey → texts.json |
| R7 | teaching:true 的教学卡：3★ 装备态只允许 1 个核心原子（修饰符可省），1★ 消耗态效果因果必须一眼可见 |
| R8 | 掉落星级策略（占位）：普通掉落**一律 1★**；2★ 掉落仅经 bounty/Boss/经济卡产生（占总量 ~5%）；3★ 及以上永不直掉 |
| R9 | 装备栏同类型唯一（占位；重复类型只能走合成/喂养/消耗） |
| R10 | 喂养合成（占位）：手牌卡与已装备的同型同星卡可直接合成升星（免卸装）。永久装备定案后其地位升级：这是**唯一**能提升已装备卡星级的途径 |
| R11 | **装备可撤销/可消耗（2026-07-14 拍板改选项B）**：装备着的卡可随时拖入战场消耗释放（触发消耗态即时效果并腾出装备位），`unequipPolicy=consume`、`equipIrreversible=false`；不设无效果的纯销毁入口，也不要求"不可逆"二段确认；消耗态仍遵守 R4（即时或 ≤5s、禁永久）；消耗高星装备代价大（见消耗价值锚），可选轻确认防误触（形式待定，非强制） |

消耗价值锚（v2.0 重写）：消耗的机会成本随星级陡增——消耗 3★ = 放弃一次入装机会；消耗 5★/6★ = 把半件/整件终极装备兑现掉（失去其全程持续效果、腾格重构），故其消耗态必须是**救场级**（全场冻结/巨额爆发/镜像代打）。旧版"溢出 3★ = 零机会成本终局大招"的循环论证随 3★ 上限一并作废：6★ 上限下高星永远稀缺，**高星消耗永远昂贵**——这是可消耗装备语义下"脑子重"的核心来源（何时兑现持续效果为即时爆发）。装备了还是消耗掉，从 3★ 起每一张都是真决策。

## 6. 主动风险选择：精英 Bounty 机制（框架级）

2026-07-10 定案：Bounty 为基础机制；**险区掉落作为原则内置其中**（赏金掉落"肥而急"）；诱饵作为控制类卡牌承载（§8 卡 5），不再另立机制。

**流程**：第 ~3 波起，每波 ~60% 概率生成 1 名 bounty 精英，头顶金色标记 + **~8s 倒计时环**（H3 可读性载体）。窗口内点击精英 = **接单**：

- 炮台索敌优先级改为 bounty > 烙印(vulnerable 标记) > 最近敌人 —— 集火精英意味着放任其余敌流逼近，突破风险上升；
- 精英**狂暴**（+速度/+HP 或召唤 ~2 护卫，占位待数值标定）；
- 击杀必掉 ~2 张掉落，2★ 权重 ~×3，但掉落时限 ~×0.6 —— **肥而急**，杀完还得立刻分心去点，险区原则的具体形态。

**不接单无惩罚**：精英按普通强敌行为，无赏金。风险是 opt-in 的——若不接单要挨罚，选择就成了伪选择。

**注意力经济**：接单动作本身与点掉落、拖卡释放争夺同一只拇指（§7）；接单后的集火期是全局压力峰，正好制造波内 1–3 次/分钟预算内的"关键点出手"时刻。

**验证钩子**：H3（点谁=选什么是否可读）→ T3 首局无指导观察；接单率/接单后死亡率/赏金掉落拾取率 → 内容实装阶段遥测埋点。

## 7. 点击动词冲突表

| 动词 | 目标 | 功能 | 典型争夺场景 |
|---|---|---|---|
| 点地面掉落 | 掉落物 | 拾取入卡槽（占容量） | 掉落将过期 vs 正在集火 bounty |
| 点 bounty 精英 | 精英 | 接单集火（敌流压力↑，报酬肥） | 窗口倒数中 vs 手里的卡该合成了 |
| 拖卡入主画面 | 落点 | 消耗释放（失去该卡，落点=锚点） | 解围窗口将关 vs 这张卡差 1 张就能合成升星 |
| 拖卡入装备格 | 装备格 | **装备（可撤销；装备着可再拖出消耗）** | 现在装 3★ 吃全程 vs 憋 5★/6★ 一步到位；装错可消耗腾格，代价=兑现掉该卡 |
| 点卡槽卡 | 手牌 | 选中/合成/喂养 | 波间呼吸口高频整理，波内偷合成要付注意力 |
| 点 perk 三选一 | 面板 | 波间成长决策 | 呼吸口内与整理卡槽竞争时间 |

设计验收标准：任一时刻屏幕上**至少两个动词同时有效**且指向不同收益，否则该波次段落是"纯挨浪"，需要回炉（秒级验收指标见 P6 文档 E1–E7）。

## 8. 首批卡牌设计（12 张）

覆盖：弹道×3、控制×3、领域×2、经济×2、防御×2；教学卡 3 张（贯穿/冲击/丰收）。
`批次 1` = 首批实装（7 张，含全部五类）；`批次 2` = 设计完成的储备。

每卡表格只列**设计锚点**：装备态 3★/5★/6★ + 放大轴（4★ 用）；消耗态 1★/3★/6★（2★/4★/5★ 内插：数值取相邻锚点线性中值，5★ ≈ 6★ 数值的 ~80% 且不含换形元素）。

---

### 卡 1 · 贯穿 `pierce`（弹道 ｜ 教学卡 ｜ 批次 1）

幻想：一击洞穿一列敌人。 ｜ 放大轴（4★）：穿透数 +1、伤害保留 +10pt

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 沿"炮台→落点"轴线发射巨型贯穿弹，贯穿全线敌人，~3× 弹伤，窄幅 |
| 3★ core | onFire：子弹穿透 ~2 个敌人，伤害保留 ~80%；修饰：每穿透 1 个，该弹伤害 +~10%（递增） | 同 1★，~5× 弹伤，宽幅 |
| 5★ dual | **+回旋**：穿透耗尽/到达射程末端的子弹撞场边反弹一次，回程再穿一程（ricochet，回程伤害 ~60%） | （内插） |
| 6★ transform | **形态·贯穿光束**：主炮换形，每 ~0.9s 发射一道贯穿全射程的直线光束，命中路径全部敌人 | 同 1★，~8× 弹伤，极宽 + 沿途击退 |

设计意图：教学卡（R7：3★ 单核心原子，1★ 消耗"一条线全穿"零解释成本）；5★ 启用保留原子 ricochet，"去而复返"与递增修饰乘出回程爽点；6★ 光束是最直观的换形示范。

## 9. 首批实装子集与复杂度预算

| 批次 | 卡 | 类别覆盖 | 设计态数 |
|---|---|---|---|
| **批次 1（首批实装）** | 贯穿、连锁闪电、冰霜、诱饵、灼痕、丰收、庇护 | 弹道2 控制2 领域1 经济1 防御1，教学卡2 | 7×(3装备锚点+3消耗锚点) = **42** |
| 批次 2（设计储备） | 分裂爆破、冲击、圣域、荆棘 | 各类补第二张 | 4×6 = 24（已设计未实装） |

6 档星级使总"效果态"名义数量翻倍，但**设计与实装成本只按锚点计**：4★ 是全局放大规则（解释器一处实现）、2★/4★/5★ 消耗态是内插规则（一处实现），逐卡新增的仅是 5★ 第二机制（每卡 1 条，全部由现有原子组合而成，未新增任何原子）。原子复用率：42 个设计态由 ~27 个原子组合而成，解释器实现一次、卡牌纯配置。

**实装顺序建议**：贯穿 → 冰霜 →（此时验证解释器的 onFire/修饰链路 + 4★ 放大规则）→ 连锁闪电（验证 onKill 二次触发）→ 灼痕 →（验证 interval/groundZone + 5★ 干柴的跨源易伤）→ 丰收 → 庇护 → 诱饵（summon 最复杂，最后）。Bounty 机制与诱饵同期做，共享索敌优先级改造。装备可撤销/可消耗（R11 选项B）在 equipmentSystem 已就位（`unequipPolicy=consume`）；可选的防误毁高星轻确认依赖 pointerRouter，随交互清单修订项走。
