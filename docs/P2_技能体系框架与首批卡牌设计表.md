## 1. 设计原则

1. **位置→注意力映射**：幸存者like 用走位消费风险，本作玩家不移动，风险资源改为**屏幕位置上的注意力分配**——掉落在哪、精英在哪、消耗卡落点选哪，都是空间决策。
2. **指针动词多功能化**：点击与拖拽共享同一只手/同一注意力通道，承担拾取、接单、装备与落点释放（见 §7）。每次操作都有机会成本。
3. **时刻型窗口**：所有压力来自"窗口会关"（掉落过期、bounty 倒计时、解围时机），不来自 APM。
4. **复杂度预算**：P5 范围为 12 张全量实装；原批次 1/2 仅保留为实现顺序，不能再解释成交付边界。
5. **题材解耦（P0-5）**：下文卡名均为机制工作名，皮肤文案经 `texts.json` 的 `textKey` 索引。

## 2. 效果原子库

原子只描述"做什么"，由上下文决定"何时何地"：装备态 = 绑定到触发器；消耗态 = 落点即时释放。**同一原子服务两种用法，是一卡两用不膨胀的关键。**

| 类别 | 原子 | 说明 | 关键参数 |
|---|---|---|---|
| 弹道 projectile | pierce | 子弹穿透 | count, damageRetention, rampPerPierce |
| | chain | 命中后向附近敌人弹跳 | bounces, damageRetention, searchRange |
| | split | 命中后分裂子弹片 | count, damageRatio |
| | ricochet | 撞场边反弹（首批未用，原子保留） | bounces |
| | aoeOnHit | 命中点小爆炸 | radius, damageRatio, falloff |
| | beamMorph / mortarMorph | 3★ 换形：光束炮 / 榴弹炮 | interval/width、radius/falloff |
| 控制 control | slow | 减速 | ratio, duration |
| | freeze | 冻结 | duration, stacksToTrigger |
| | stun | 眩晕 | duration, chance |
| | knockback | 击退 | distance, collisionDamage |
| | taunt | 嘲讽（改索敌目标） | radius, priorityWeight |
| | vulnerable | 易伤 | ratio, duration |
| 领域 domain | aura | 炮台中心持续光环（内嵌其他原子） | radiusRatioOfRange, effects[], tickInterval |
| | groundZone | 地面区域（点/环带，内嵌 dot/slow 等） | radius, duration, tickInterval, effects[], shape |
| | dot | 持续伤害 | damagePerTick, tickInterval, duration |
| | summon | 召唤物：诱饵图腾/镜像炮台/环绕球 | kind, count, hp, duration, behaviors[] |
| 经济 economy | dropRateMul / dropLifetimeMul / xpMul | 掉率/掉落时限/经验乘数 | mul |
| | extraDrop | 直接产生掉落 | count, starWeights, at |
| | expiryConvert | 过期掉落转化（破"过期即损失"） | ratio, convertTo |
| | mergeRule | 改合成规则本身（万能卡/返还） | rule, value |
| | mergePulse | 合成动作产生战斗效果 | damagePerMergeCount, radius |
| 防御 defense | shield | 炮台护盾（按可吸收突破次数计） | absorbHits, regenSeconds |
| | thorns | 反伤 | ratio |
| | breachReduction | 突破惩罚减免 | ratio |
| | novaOnBreak | 破盾新星 | damage, knockbackDistance |
| | execute | 低血线处决 | hpThresholdRatio |
| 共用 shared | burstDamage | 即时范围伤害（消耗态常用） | damageMul, radius |
| | focusPriority | 改炮台索敌优先级（bounty/烙印联动） | priorityWeight |

**正交性约束**：新增效果先问"能否由现有原子+参数组合表达"，不能才加原子。原子之间不允许隐式互相引用（组合语义由解释器叠加，如"冻结中的敌人受击退无效"这类交互规则集中写在解释器的冲突表里，P3 交付）。

## 3. 触发器库

| 触发器 | 时机 | 上下文载荷 | 对应现有 GameEvent |
|---|---|---|---|
| onFire | 炮台发射子弹 | bullet | （新增，combatSystem 开火点） |
| onHit | 子弹命中敌人 | bullet, enemy, hitPoint | （新增，命中判定点） |
| onKill | 敌人死亡 | enemy, killPoint | （新增，死亡结算点） |

| onBreach | 敌人突破触及炮台 | enemy, damage | `breakthrough` 已有 |
| onPickup | 点击拾取地面掉落 | drop | `collected` 已有 |

GameEvent 流就是现成的触发器总线，P3 只做扩展不做重建。

## 4. 星级质变模板（硬规则 R5，v1.1 按入装门槛 2★ 重构）

| 星级 | 模板 | 定义 | 判据 |
|---|---|---|---|
| 1★ | material 素材/即时 | **不可装备**。两个出路：合成素材（2 张同型 → 2★）或即时消耗（该幻想的最小剂量） | 拾取时的取舍（合还是扔）3 秒内可判断 |
| 2★ | core 机制成形 | **首次装备体验**：基础机制 + 1 个修饰符 | 一句话能说清机制，修饰是"啊还会这样"的小惊喜 |
| 3★ | transform 形态变换 | 可整体替换触发绑定：换形/领域化/召唤物化 | 视觉形态肉眼可辨，构筑身份改变 |

质变逐级发生：1★→2★ = **获得装备身份**（从弹药变成部件），2★→3★ = **形态变换**。3★ 是构筑的"身份宣言"——玩家报 build 时说的是 3★ 形态名（雷暴、榴弹、镜像炮台）。

合成经济骨架（P4 复检）：二合（3★ = 4 张同型），基座采用方案B **共享 10 格、最多锁 3 张、锁定即装备**；方案A的手牌7+装备3只作 variant。装备同类型唯一，支持喂养合成。

## 5. 一卡两用硬规则（R1–R10）

| # | 规则 |
|---|---|
| R1 | 每张卡**必须**定义：2★/3★ 装备态 + 1★/2★/3★ 消耗态（1★ 不可装备，见 R5）。消耗态 = 同一幻想的压缩即时版，只能复用该卡装备态的原子家族（不得为消耗态发明新机制） |
| R2 | 消耗释放 placement 恒为 point：**释放点 = 落点**。落点是效果的空间锚点——中心（AoE/冻结/燃海）或方向轴（贯穿），由原子语义决定 |
| R3 | 消耗即失去该卡（从卡槽移除，不返还） |
| R4 | 消耗态即时生效或持续 **≤5s**，禁止任何永久效果；强度/半径随星级按表增长 |
| R5 | 星级质变模板见 §4：1★ 素材/即时（不可装备）→ 2★ 机制成形 → 3★ 形态变换；禁止"3★=2★数值×1.5"式伪升级 |
| R6 | 题材解耦：名称/描述一律走 textKey → texts.json |
| R7 | teaching:true 的教学卡：2★ 装备态只允许 1 个核心原子（修饰符可省），1★ 消耗态效果因果必须一眼可见 |
| R8 | 掉落星级策略：普通掉落**一律 1★**；2★ 掉落仅经 bounty/Boss/经济卡产生（占总量 ~5%），3★ 永不直掉 |
| R9 | 装备栏同类型唯一（重复类型只能走合成/喂养/消耗） |
| R10 | 喂养合成：手牌卡与已装备的同型同星卡可直接合成升星（免卸装）。这是低槽压的关键（砍掉≈手牌 −1 格） |

消耗价值锚（风险清单 #4 预警）：消耗 3★ = 放弃一件永久装备，机会成本极高，故 3★ 消耗态必须是**救场级**（全场冻结/巨额爆发/镜像炮台代打）。若拾取预算落在锚点窗口上沿（N≈45），一局约合成 ~5 件 3★ 而装备仅 3 格——溢出 3★ 消耗零机会成本，即终局大招，风险 #4 在成型后自动消解（**条件性结论**：N≈30 时仅溢出 ~1 件，循环不成立，随 P4 锚点实测复核）；P4 需保证 Boss 强度吃得下 1–2 发救场级消耗。

## 6. 主动风险选择：精英 Bounty 机制（框架级）

2026-07-10 定案：Bounty 为基础机制；**险区掉落作为原则内置其中**（赏金掉落"肥而急"）；诱饵作为控制类卡牌承载（§8 卡 5），不再另立机制。

**流程（P4.1 模型基座）**：第 3 波起，每波 55% 概率至多生成 1 名 bounty 精英，头顶金色标记 + **8s 倒计时环**。窗口内点击精英 = **接单**：

- 炮台索敌优先级改为 bounty > 烙印(vulnerable 标记) > 最近敌人 —— 集火精英意味着放任其余敌流逼近，突破风险上升；
- 精英狂暴：标准档速度 ×1.35、HP ×10；难度 variant 可覆盖；
- 击杀必掉 2 张，2★ 权重 ×3，掉落寿命 ×0.6 —— **肥而急**。

**不接单无惩罚**：精英按普通强敌行为，无赏金。风险是 opt-in 的——若不接单要挨罚，选择就成了伪选择。

**注意力经济**：接单动作本身与点掉落、拖卡释放争夺同一只拇指（§7）；接单后的集火期是全局压力峰，正好制造波内 1–3 次/分钟预算内的"关键点出手"时刻。

**验证钩子**：P4.1 遥测与共享队列已实现；H3（点谁=选什么是否可读）仍须 T3 首局无指导观察。接单后死亡不能直接解释为 Bounty 致死，需 T2/T3 或反事实实验。

## 7. 点击动词冲突表

| 动词 | 目标 | 功能 | 典型争夺场景 |
|---|---|---|---|
| 点地面掉落 | 掉落物 | 拾取入卡槽（占容量） | 掉落将过期 vs 正在集火 bounty |
| 点 bounty 精英 | 精英 | 接单集火（敌流压力↑，报酬肥） | 窗口倒数中 vs 手里的卡该合成了 |
| 拖卡入主画面 | 落点 | 消耗释放（失去该卡，落点=锚点） | 解围窗口将关 vs 这张卡差 1 张就能合 3★ |
| 点卡槽卡 | 手牌 | 方案B：锁定/解锁即装备 | 波间呼吸口高频整理，波内偷装备要付注意力 |
| 点 perk 三选一 | 面板 | 波间成长决策 | 呼吸口内与整理卡槽竞争时间 |

设计验收标准：**每个预定压力节点**至少提供两个指向不同收益的有效窗口；不要求呼吸口也同时存在。P4.1 用滚动动作峰值、共享队列延迟、窗口重叠和注意力额外过期量化。

## 8. 首批卡牌设计（12 张）

覆盖：弹道×3、控制×3、领域×2、经济×2、防御×2；教学卡 3 张（贯穿/冲击/丰收）。
`批次 1/2` 仅表示 P5 全量 12 张内的建议实现顺序。

---

### 卡 1 · 贯穿 `pierce`（弹道 ｜ 教学卡 ｜ 批次 1）

幻想：一击洞穿一列敌人。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 沿"炮台→落点"轴线发射巨型贯穿弹，贯穿全线敌人，~3× 弹伤，窄幅 |
| 2★ | onFire：子弹穿透 ~2 个敌人，伤害保留 ~80%；修饰：每穿透 1 个，该弹伤害 +~10%（递增） | 同上，~5× 弹伤，宽幅 |
| 3★ | **形态·贯穿光束**：主炮换形，每 ~0.9s 发射一道贯穿全射程的直线光束，命中路径全部敌人 | 同上，~8× 弹伤，极宽 + 沿途击退 |

设计意图：教学卡（R7：2★ 单核心原子，1★ 消耗"一条线全穿"零解释成本）；3★ 光束是最直观的换形示范。

### 卡 2 · 连锁闪电 `chainLightning`（弹道 ｜ 批次 1）

幻想：电弧在敌群中跳跃。（计划文档钦定示例）

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点雷爆：对最近敌人放电并连锁 ~4 个 |
| 2★ | onHit：弹跳 ~2 次，跳跃伤害 ~70%，搜索半径 ~120；修饰：每跳附带减速 ~20%/1.2s | 连锁 ~7 个 + 减速 |
| 3★ | **形态·雷暴领域**：interval ~1.2s，对射程内至多 3 个敌人放电、各链 2 次（不再依赖子弹命中） | 连锁 ~12 个 + 眩晕 0.5s |

设计意图：密集敌群的 payoff 卡；3★ 从"弹道修饰"跃迁为"环绕领域"，是星级质变的标杆示例。

### 卡 3 · 分裂爆破 `splitBlast`（弹道：分裂+AoE ｜ 批次 2）

幻想：一发变一片。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点爆炸：半径 ~110，~4× 弹伤 |
| 2★ | onHit：分裂 ~2 枚子弹片（~50% 伤害，随机方向）；修饰：子弹片命中再触发小 AoE（半径 ~40，~60%） | 半径 ~140，~6× + 炸出 4 枚子弹片 |
| 3★ | **形态·榴弹**：主炮换形抛射榴弹，落点 AoE（半径 ~90，边缘衰减 50%） | 半径 ~180，~9× + 二次余爆 |

设计意图：与贯穿构成"线 vs 面"的弹道构筑分岔。二批：与贯穿同类别，首批留一个换形示范即可。

### 卡 4 · 冰霜 `frost`（控制：减速/冰冻 ｜ 批次 1）

幻想：让世界慢下来。（计划文档钦定示例）

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点大范围冻结 3s，半径 ~90 |
| 2★ | onFire：子弹附带减速 ~30%/1.5s；修饰：同一敌人叠 ~3 层触发冻结 0.8s | 半径 ~130 + 解冻后残留减速 |
| 3★ | **形态·极寒领域**：射程 60% 半径光环持续减速 ~35%，每 ~4s 释放一圈冻结波（0.6s） | 半径 ~170 + 冻结中受伤 +~30%（易碎） |

设计意图：一卡两用规则的钦定示例；消耗态是最典型的"救场级"窗口技。

### 卡 5 · 诱饵 `decoy`（控制：嘲讽 ｜ 批次 1）

幻想：让它们打错目标。——**主动风险选择的卡牌化身**：把敌流拉离突破口，或反向拉走小怪以便集火 bounty 精英，是"选择面对哪股敌人"的主动版。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点放置诱饵 4s，半径 ~120 内敌人立即转向 |
| 2★ | onWaveStart：随机位置生成 1 座诱饵图腾（低 HP，嘲讽半径 ~140）；修饰：图腾被摧毁时爆炸击退周围敌人 | 半径 ~160 + 摧毁/到期时爆炸 |
| 3★ | **形态·镜像炮台**：图腾替换为会开火的镜像（~30% 本体伤害，全场嘲讽权重）；镜像存在期间本体射速 +~10% | 落点镜像炮台 5s（代打救场） |

设计意图：改变"敌人只会冲炮台"的单调压力结构；与 bounty 机制天然互锁。

### 卡 6 · 冲击 `impact`（控制：击退 ｜ 教学卡 ｜ 批次 2）

幻想：把它们轰开。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点冲击波：半径 ~100 击退 |
| 2★ | onFire：子弹附带击退 ~22px；修饰：被击退者撞上其他敌人时双方受碰撞伤 | 半径 ~140 击退 + 眩晕 0.5s |
| 3★ | **形态·新星脉冲**：interval ~4s 全向冲击波，射程 50% 内击退 + 眩晕 0.4s | 半径 ~180 强击退 + 眩晕 1s + 碰撞伤 |

设计意图：教学卡（打中→飞出去，因果零解释）；二批：控制类首批已有冰霜+诱饵两张。

### 卡 7 · 灼痕 `scorch`（领域：地面区域+DoT ｜ 批次 1）

幻想：所过之处皆成火海。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点燃海：半径 ~110，3s 持续 DoT |
| 2★ | onHit：命中处留灼烧区（半径 ~40，2.5s，每 0.5s ~15% 弹伤）；修饰：敌人死于灼烧区时向死亡点扩散一块新灼烧区 | 半径 ~140，4s + 燃烧中受击 +~15% |
| 3★ | **形态·烈焰环带**：以炮台为中心的常驻环形火圈（内径~射程 40%，环宽 ~60），圈内 DoT + 微减速 | 半径 ~180，5s + 死亡扩散 |

设计意图：领域类代表；2★ 扩散修饰制造"链式烧穿一波"的爽点时刻。

### 卡 8 · 圣域 `sanctum`（领域：光环/易伤 ｜ 批次 2）

幻想：进入领域者皆被审判。

| 星级 | 装备态 | 消耗态（落点） |
|---|---|---|
| 1★ | —（素材/消耗） | 落点烙印：半径 ~110 易伤 +~30%，4s |
