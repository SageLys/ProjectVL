## 三、main 分支七阶段时间线

### 阶段 0 · 工程重构（07-07，7 commit，1 天）
单文件原型 → Vite+TS 工程化：抽出 `core/`（纯规则层，38 项 Vitest 全绿）、`render/ui/input` 三层分离、数值文案外置到 `src/data/*.json`。这是整个项目的地基提交，`main.ts` 收敛为薄胶水层。

### 阶段 1 · 策划重启与差距盘点（07-10～07-13）
`docs: 添加当前版本策划与模拟资料` → `重构配置并实现技能效果系统` → **`定案六星技能与不可逆装备设计`** → **`制定可玩原型重启计划`**（tag `restart-s0`）→ **`完成 S0 设计代码差距盘点`**。随后是移动端交互专题：T1 触控校准、竖屏三分区布局、指针输入统一、装备独立流程、skills schema 升到 v0.4.0。

对应文档：`docs/S0_差距盘点报告.md`、`docs/可玩原型_重启开发总计划.md`、`docs/T1_触控校准记录.md`

### 阶段 2 · 数值节奏与内容批次（07-13～07-17）
预算式刷怪（`Add budget-based wave spawning`）、多波 Boss、可调经验与随机 Perk 池、技能卡 batch-1/batch-2 实装、视觉编码重构（技能徽标体系、敌人形状化）、阶段4卡牌文案与升级反馈。**赏金机制重做**是这一阶段的核心系统性工作：模型重构 → 报价导演 → 敌群结算 → 优先索敌 → 视觉反馈 → 遥测接入，6 个 commit 一天内完整走完设计-实装-验证闭环（07-16）。随后加入难度框架并做曲线微调。

### 阶段 3 · 战斗体验与控制感重构（07-21～07-24 前半）
`add three-stage run director and drop pacing`（三阶段体验导演）、奖励星级曲线、装备/手牌对调、**射程限位与控制预算/潜力封顶**（对应 `codex-prompt-控制体验重构` 文档）、战斗表现层兼容性覆盖矩阵、速度控制、光束 DPS 修复、Boss 贴身持续伤害重构。

### 阶段 4 · C0-C9 决策与进化系统首版（07-23～07-24）
这是设计文档 `codex-prompt-C0` 到 `codex-prompt-C8` 对应的落地窗口，也是 memory 中"C0-C9 全完成"节点：数据契约兼容层 → 决策队列与波间阶段 → 波末基础奖励 → 神池与本波活跃池 → 遗物化经验升级 → 单卡进化树 → 卡间进化 → 随机数值槽 → 五神35卡内容落地。同期还有 `card affixes and recipe evolution`、`evolution branches card-specific`、防御反馈 VFX、卡牌详情 UI。

### 阶段 5 · 配置管线与内容设计工具化（07-26～07-29）
"固化1-4"系列（效果原子参数契约、配置清理、黄金回放基准、配置管线 v1）→ **配置编辑器 v1（表单式）** → Excel 双向同步 → 掉落导演配置清理 → **内容设计工作台**（只读 → 内联文案编辑 → 多域联动保存，三步迭代）。同期修完武器融合遗留问题（装备被动融合契约、主炮形态融合半径/威力缩放）。这一阶段本质是把"策划改数值要不要求工程师"这件事系统性解决掉。

### 阶段 6 · 大重构冲刺（07-29～07-31，单日 20 commit 峰值在 7-30）
- mergeRule 退役，经济类效果原子改为零行为契约；召唤物/几何区域重写并重录黄金回放基准
- **35 卡全字段重写 + 25 格 B0 配方进化系统定稿**（对应 memory「卡牌进化系统定稿」：25 格有向矩阵、零配方局结构性为 0、即时拖拽）
- **奖励蓄力条重构**：`relic progression` → `reward meter`，替换经验/遗物为自动抽奖机制（对应 memory「奖励蓄力条重构 Prompt」），过程中有 `checkpoint before reward meter refactor` 的显式风险备份提交，并留了两个 archive 分支兜底
- 基础属性词条分区（乘区拆分）、竖屏 UI 适配与波末流程顺序重构

### 阶段 7 · 事故恢复与收尾（07-31～08-04）
