## 1. 通用交互定义（两方案共享）

竖屏三段式布局：HUD 条 / 主画面（释放区）/ 底部 dock（拇指热区）。装备区从画面左侧绝对定位移入底部 dock，跨屏拖拽消灭。

| 动词 | 语境 | 结果 |
|------|------|------|
| 单击主画面 | 命中掉落拾取半径内 | 拾取最近掉落 |
| 单击主画面 | 命中精英 bounty | 接单（集火+狂暴） |
| 拖卡 → 主画面抬指 | 任意星级手牌卡 | 消耗释放，落点=抬指点换算的画布坐标 |
| 拖卡 → 卡格 | 手牌内 | 移动/交换（触发自动合成） |
| 拖卡→装备格 | ≥3★ 手牌卡 | **永久装备（不可逆，经确认后生效）** |

判定规则：
- **点击 vs 拖拽**：pointerdown 后位移 < 8px 且 < 150ms 判点击，否则进入拖拽（T1 手机实测定案，2026-07-13）。此阈值是主画面「点击拾取」不误触发的前提。
- **手指遮挡**：拖拽中落点预览环偏移显示在手指上方 Δy=30px（T1 手机实测定案，2026-07-13）。实际落点 = 预览环圆心，非手指位置。预览环半径读 `skills-schema` 的效果原子 AoE 参数；无落点语义的卡（纯 buff 压缩版）显示全屏微光而非预览环。
- **释放取消**：拖回 dock 区域抬指 = 取消，卡回原格。拖出屏幕/被打断（pointercancel）同取消。
- **PC 适配**：同一套 pointer 事件天然覆盖鼠标；快捷键（数字键 1–7 选卡+点击释放）进 P6 输入适配层，本次不做。

## 2. 方案A：独立装备格（**定案基座**，v2.0）

见 `wireframes/交互线框_方案A_独立装备格.svg`。

- dock 两行：装备 3 格（上，紫框大格）+ 手牌 7 格（下）。装备/手牌拖拽路径 ≤ 90px。
- 装备动词：**仅拖入装备格**（双击/长按快捷装备取消——不可逆操作不配轻量动词，重动作本身就是第一道防误触）。
- **不可逆确认（R11）**：拖卡悬停装备格时格位转警示金框 + "永久"标签 + 该卡装备态预览；抬指后**二段确认**（格位原地弹出确认气泡，点确认才生效；确认形式与时长 T1 实测定）。确认前明示"此操作不可撤销"。
- **卸下 = 纯销毁**：长按已装备格 → 弹销毁确认（红色语义，显示将失去的星级/机制）→ 确认后格位清空。无任何返还。
- 门槛 **≥3★**（配置 `equipMinStar: 3`）；同类型唯一（占位），拖入同型同星 = 喂养合成升星（不触发不可逆确认——喂养不改变承诺，只强化它）。
- 空装备格常显淡金 "3★+" 水印，向玩家预告门槛。

## 3. ~~方案B：锁定即装备~~（**已废弃**，2026-07-12：锁定可逆与永久装备冲突；线框留档不删）

见 `wireframes/交互线框_方案B_锁定即装备.svg`。

- 共享池 10 格（2×5），无独立装备区。单击 ≥2★ 卡 = 锁定（=装备生效，上限 3），再击解锁。

- 主画面交互与方案A 完全一致——A/B 只隔离「装备操作」单一变量。
