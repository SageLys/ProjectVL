| 「三角色掉落袋是我设计的」 | 你提的是方向性体验目标，机制与命名是 ChatGPT 的 |
| 「我跑了 A/B 实验选定装备交互方案」 | 判据从未执行，靠语义冲突 + 易用性直接裁决 |
