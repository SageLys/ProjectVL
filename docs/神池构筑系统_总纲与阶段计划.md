# 神池构筑系统 总纲与阶段计划（C 系列）

日期：2026-07-23
状态：**定稿（已拍板）**。本文件是 C0–C8 各 codex-prompt 的总目录与共同契约；具体实施细节以各阶段 prompt 为准。
关联：`docs/神池系统_设计方案_v1.md`、`docs/五神卡牌设计表_v1.md`（35 卡正式内容）、`docs/普通掉落导演_设计说明.md`。

## 一、需求总述

在现有战斗系统之上新增一层完整的**单局构筑编排层**：

> 选神 → 生成本局卡组 → 每波激活子池 → 卡牌分支成长（进化树）→ 卡间进化（配方）→ 遗物导流（经验升级重做）→ 波末基础成长。

现有"数据定义 + 通用效果原子 + 解释器"架构保留并大量复用；卡牌实例、自动合成、波间流程、升级系统与所有随机掉卡入口需要结构性改造。

## 二、已拍板的关键决策

1. **神 = 重新设计后的流派**。新增 `GodId`（卡牌字段 `god`）作为流派身份，决定卡池归属、选神、遗物池与包装。旧 `BuildTag`（projectile/control/domain/defense/utility）**降级为机制标签**，仅供遗物缩放（`buildModifierSystem`）按原子参数白名单作用，不再代表流派。不得把神映射为现有 BuildTag 枚举值。
2. **一主神二副神**：第 1 波 3 选 1 定主神（2 锚点 + 5 可变抽 3 = 5 张），第 2/3 波各 2 选 1 定副神（2 锚点 + 抽 1 = 3 张），第 3 波末锁池。本局名册固定 11 张。
3. **三级合法卡范围**：全局卡库 → 本局卡组（11）→ 本波活跃池（5–7）。普通掉落只从活跃池出；Bounty 从本局卡组出；validation 高星奖励按当前重点神定向；任何正常路径不得出现第四神的卡。
4. **主配置改 10 波**：`totalWaves=10`，3 招募 + 5 收敛 + 2 兑现；第 10 波即终局 Boss 波，不追加独立 Boss 段。`betweenWaves` 由固定 2.4s 改为正式波间阶段（阶段曲线 + 显式"准备完成"）。
5. **波末基础成长**：改为“保底自动 + 每波五选一”。保底层每波自动结算回血、小额基础伤害与未触顶时的射程；选择层每波从基础伤害、基础射速、心防上限、射程、经验取得中选择 1 项，当波结算且不跨波贮存。成长使用**基数加法**并禁止百分比永久成长；唯一例外是选择层的 `xpGainPct`，因为经验取得本质为乘性且无法基数化。保底层严禁 pct，选择层除 `xpGainPct` 外也严禁 pct。
6. **经验升级专供遗物**：5–8 个/局，显式 XP 阈值表替代 `xpNeed *= 2`，前期高密度低品质、后期低密度高品质；遗物候选只来自已选三神 + 中立池；掉落导流 affinity 从 BuildTag 改为按神。
7. **单卡进化树**：1★基础 → 2★数值 → 3★分叉(3 选 1) → 4★公共节点 → 5★分叉(3 选 1) → 6★公共终态。分支选择**按本局卡族锁定**（同名卡本局只选一次、后续继承），5★ 分支与 3★ 分支独立组合（3×3 路径）。关键星合成产生"待决结果"进入决策队列，暂停连锁合成。
8. **卡间进化 ≠ 融合**：VS 式固定配方（两张指定 5★ 卡 → 一张预设 6★ 新卡），只在波间手动确认。任意融合/词条镶嵌延后。
9. **技能效果槽与数值槽分离**：每卡型每局随机一次"词条模板"（同卡型本局共享，防自动合成吞词条）；装备=持续生效，消耗=限时 Buff。`Buff` 扩展为通用 `RuntimeStatModifier`。
10. **统一构筑决策队列**：`DecisionQueue`（选神/选房/进化分支/配方/遗物）替代散落布尔值；有决策则暂停，队列清空才能继续。现有 `pendingLevelUps + offeredPerks` 在 C4 并入。
11. **35 卡内容已定稿**：见 `docs/五神卡牌设计表_v1.md`（5 神 × 7 张，含全部进化树/消耗态/词条池/配方），Codex 照表实施，数值为占位、C9 仿真标定。

## 四、共同契约（每个阶段 prompt 均默认遵守）

1. 分层不破坏：`src/core` 无 DOM；随机数一律经注入 `rng`；表现由 `GameEvent` 驱动。
2. 每阶段结束 `npm test` 与 `npm run build` 通过；改规则必须补规则测试。
3. 效果表达优先复用现有 31 个原子；只有无法表达且服务多卡的效果才新增原子（C8 新增清单已在设计表 §7 列明）。
4. 新配置一律走 `src/config` JSON + 校验器，禁止核心层为单卡写 if。
5. 固定 RNG 下整局可重现；新增系统均补遥测事件（各阶段 prompt 附清单）。
6. 文件行号仅供导航，以符号名为准。

## 五、明确延后（只留数据接口，不做 UI 与规则）

## 六、整体验收（C8 完成后）

1. 未选神的卡不会从任何入口（普通/Bounty/波末/validation/skillExtra/调试默认档）出现。
2. 一局固定一主二副、名册 11 张、活跃池 ≤7 张、第 3 波锁池。
3. 波末保底与五选一分别恰好结算一次；未选 4 项不补发。除选择层 `xpGainPct` 这一显式例外外，无百分比永久成长。
4. 普通完整局遗物 5–8 个，品质前低后高；遗物只来自已选神 + 中立。
5. 关键星合成必出 3 分支选择；同卡族本局只选一次；配方进化精确消耗两张材料。
6. 每卡型词条模板本局一致；装备持续、消耗限时。
7. 五神各自覆盖伤害/控制/防御/资源，全部技能可叠加且存在跨神乘法接口。
8. 固定 seed 整局重现；遥测覆盖 god_offer/god_selected/active_pool_created/evolution_branch_selected/recipe_completed/relic_selected/wave_rewards_granted/affix_rolled 等。
