## 2. 默认值核对结果：33 原子逐项差异 = 0

## 3. 核对中发现的三类「一个参数多个默认值」（已建模，非差异）

契约新增两个可选字段承载它们，保证 Unity 侧能拿到完整事实：

| 参数 | 触发路径 | 另一路径 | 契约字段 |
|---|---|---|---|
| `pierce.damageRetention` | 装备态改写子弹：0.8 | 消耗态巨型贯穿弹：1 | `consumeDefault` |
| `aura.tickInterval` | 消耗态落点区域：0.8 | passive 常驻光环聚合：1 | `passiveDefault` |
| `execute.hpThresholdRatio` | 触发式处决：0.15 | passive 聚合的缺省贡献：0（不处决） | `passiveDefault` |
| `summon.tauntRadius` | 140 | `kind='orbital'` 时 0 | `variantDefaults{on:'kind'}` |
| `statBuff.value` | `operation='mul'` 时 1 | `operation='add'` 时 0 | `variantDefaults{on:'operation'}` |

这些此前散落在四个函数里、彼此不知情；现在集中在一张表上，且被冻结快照测试逐条锁住。

## 4. 核对中暴露的既有漂移（本次**只记录不修**，避免混入行为风险）

1. **`summon.fireInterval`**：`skills.json` 有 3 处声明，运行时从不消费（`mirrorTurret` 固定 0.7s、`orbital` 固定 0.25s 冷却）。契约已声明该参数并加注，数值标定阶段需决定「实现它」还是「删数据」。
2. **`taunt.priorityWeight`**：数据有 2 处，`applyTaunt` 不读取。契约声明但**故意不给默认值**（没有运行时默认值可抄）。
3. **`groundZone.shape: 'line'`**：数据有 1 处，而 `Zone.shape` 只实现 `circle | ring`，`line` 当前按 circle 几何结算。契约枚举保留 `line` 并加注，属待办而非本次可改。
4. **`mergeRule` 原子零使用**：33 原子中唯一未被任何卡使用的原子，其默认值只在 `getModifiers` 中出现。

## 5. 两处语义收紧（对当前数据行为等价，已核验）

| 位置 | 迁移前 | 迁移后 | 影响 |
|---|---|---|---|
| `summon.explode` | `p.explode ? …`（真值判断） | 只认 boolean，否则取契约默认 false | 现有数据全为 `true`，行为一致；且与 `equipmentSummonMatches` 原有的 `=== true` 严格判断统一 |
| `mergeRule.rule` | `String(p.rule ?? '')` | 只认 string，否则取契约默认 `''` | `mergeRule` 零使用，无影响 |

## 6. 校验器强度变化（现有 `skills.json` 全量通过）

新增拦截：未在契约声明的参数、必填参数缺失、类型不符、超出 min/max、非法枚举值、非法触发器名、原子绑定到不被允许的触发器（`pierce`/`ricochet` 仅 `onFire`，`aura` 仅 `passive`）、原子出现在不支持的形态（装备态/消耗态）、嵌套 `effects` 出现在非领域原子上。
保留原有的跨参数约束（`restore` 必须声明 `amount` 或 `amountRatio`；`statBuff.duration > 0`；`operation='mul'` 时 `value > 0`）。

## 7. 未覆盖 / 后续

- **原子处理器签名仍是 `(ctx, params: Record<string, unknown>)`**：本次只强类型化了**数据侧**（`EffectDef`），实现侧仍走松散字典（`effectParams()` 是唯一边界）。逐原子强类型化处理器是可选的后续项，与 Unity 移植不冲突。
- **`docs/skills-schema.json` 的 `atomCatalog` 未删**：它现在是契约的下游文档，参数目录已不再是权威。配置管线 v1（T0.4/S1-B）应改为**由 `ATOM_CONTRACT` 生成** JSON Schema，届时删除手写目录。
- 第 4 节的四项漂移交给数值标定阶段处理。
