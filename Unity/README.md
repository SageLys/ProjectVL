# ProjectVL 团结版

当前项目使用团结引擎 `2022.3.62f3c1`，目录为：

`Unity/ProjectVLUnity`

## 在团结编辑器中测试

1. 打开团结 Hub。
2. 点击“打开”或“添加已有项目”。
3. 选择 `Unity/ProjectVLUnity` 文件夹。
4. 在 Project 面板中打开 `Assets/ProjectVL/Scenes/Main.unity`。
5. 点击编辑器顶部的播放按钮。
6. 点击 `START`，或按空格键开始。

操作：

- `Space`：开始
- `P` 或 `Escape`：暂停/继续
- `R`：重新开始
- 右上角 `0.5x / 1x / 2x`：切换速度

## 构建 Windows 版本

在团结编辑器菜单中选择：

`ProjectVL > Build Windows`

生成位置：

`Unity/ProjectVLUnity/Builds/Windows/ProjectVL.exe`

`Builds` 是本机生成目录，不会提交到 Git。

### 卡牌与装备测试

- `G`：向手牌加入 3 张三星测试卡。
- `1`～`7`：选择手牌槽；`Q`、`W`、`E`：选择装备槽。
- 先选择卡牌，再选择目标槽，可进行移动、交换、装备或同类喂养。
- `C`：消耗当前选中的手牌或装备卡。
- `M`：加入四张同类一星卡和各星级万能卡，测试连续自动合成。
- `V`：使用与选中卡当前星级相同的万能卡升星。
- `H`：加入五星「穿透 + 灼烧」固定配方测试材料。
- `F`：在波间阶段制作当前可用的固定配方。
- 装备卡至少需要三星，装备栏不允许出现重复类型。
- 卡牌到达三星和五星时会暂停战斗，必须先完成三选一进化。
